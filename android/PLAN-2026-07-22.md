- **E15** — root cause was NOT a remount (logs showed no dispose). The meditation
  disc's `pressScale` `.scale()` graphicsLayer went blank whenever the tree
  stopped invalidating (the 500ms position poll halts on pause) — visible only
  while pressed/animating. Fix: plain `clickable` on the disc (no graphicsLayer).

  `youtube.com` → self-embed refused) and then black video (audio only). Fixed by
  adopting **`com.pierfrancescosoffritti.androidyoutubeplayer:core:13.0.0`** (the
  iOS-YouTubePlayerKit equivalent) — it handles origin + video-surface. The
  separate lesson-MP4 HEVC issue is still real → re-encode per
  `VIDEO_REENCODE_LIST.md`.
- **Community tab** — nested `Scaffold` re-added the bottom inset → blank strip
  above the tab bar. Fixed by zeroing the inner Scaffold's `contentWindowInsets`.

**J49 / J50 — deep linking DONE + group-join verified end-to-end on device
(2026-07-22).** Root cause was the manifest declaring the `clear30` scheme and the
`https`/`clear30.org` host in ONE intent-filter (Android then required
`clear30://` URLs to also have host `clear30.org`, so they never resolved). Split
into two filters. Also fixed a join bug: the deep-link effect cleared
`pendingSubRoute`, which re-keyed `LaunchedEffect(sub)` and cancelled the in-flight
join RPC → now runs on `Clear30Application.appScope`. Referral `?code=` handler
added. Verified: `clear30://group?group_id=<real>` added a real
`groups.group_members` row via the prod backend. See `DEEP_LINKING.md`.
